## 1. 범위 (두 군데만)

| | 기능 | 지금 | 바뀌는 것 | 검증(지어내기 방지) |
|---|---|---|---|---|
| A | **업무정의서 AI 변환** | 규칙 변환(절 제목 모양), 업무가 여럿인 문서·규정집은 못 나눔(F23-5) | 「가져오기·내보내기」 문서 탭에 「AI로 변환」(키가 있을 때만 보임). Claude가 유니버스 JSON(노드·연결·메모)을 만들고, **노드마다 원문 인용 구절(quote)** 을 함께 냄 | 앱이 quote가 원문에 **부분 문자열로 실제로 있는지** 검사. 없으면 그 노드·메모는 버리고 "근거 없음 n건 제외" 표시. 그다음 기존 미리 보기(절 → 노드 표)·validateDocument → 사람이 확인하고 가져오기 |
| B | **초안·인사이트 설명 문장 다듬기** | 사전 생성(샘플) / 규칙 기반 | 키가 있으면 같은 자리에서 실시간 호출(근거 덤프만 보냄). 응답 문장마다 근거 ID + quote | 기존 근거 ID·지문 검증 + quote 부분 문자열 검사. 실패 문장은 규칙 기반으로 대체, 「규칙 기반으로 대체함: 근거 불일치」 표시 |

**하지 않는 것:** 사내 LLM 공급자(자리만 유지), 통합 후보 AI 연관 찾기(다음 단계), 서버 중계, 키 암호화 저장(브라우저 저장소 평문 — 한계로 명시), 비용 집계.

## 2. 설계 변경 (02-design)

- **D-33 호출 방식:** 브라우저에서 Anthropic Messages API를 직접 호출(공식 CORS 헤더 `anthropic-dangerous-direct-browser-access: true`, 확인 필요 — 공식 문서 URL·확인일을 tech-record에 기록). 모델·요금은 공식 문서 확인 후 기록(여기서 수치를 적지 않음).
- **비동기 연결부:** `llm/connector.js`의 refineDraft·explainInsight·convertDocumentWith를 async로. 화면은 **규칙 기반(또는 사전 생성) 결과를 먼저 그리고**, 응답이 오면 항목 단위로 교체(R-04 ③). 「생성 중…」 표시, 시간 초과(상수, 예 20초) → 규칙 기반 유지 + 원인 표시. 사용자가 화면을 떠나면 응답을 버림.
- **공급자 `claude_api`:** 설정 창에 「API 키」 입력 칸(비밀번호 칸, 이 브라우저에만 저장 `wu:v1:settings.apiKey` — 12.4 보강, 내보내기·내용 포함 HTML·폴더 거울·되감기 이력에 **절대 포함하지 않음**). 키가 없으면 지금처럼 "연결 전" 안내.
- **빌드·CSP:** `tools/build.mjs`의 `fetch(` 금지는 `llm/providers.js` 한 파일만 예외(주석 표지로 검사). CSP `connect-src 'none'` → `connect-src https://api.anthropic.com`. 비밀값 검사는 그대로(키 문자열이 파일에 없어야 함).
- **프롬프트 재료:** `tools/pregen-dump.mjs`의 근거 글 만들기(describe)를 `llm/` 아래로 옮겨 공급자가 쓴다 — "규칙이 고른 근거만 보낸다"를 코드로 보장.
- **캐시:** 응답을 (조회 키, 지문)으로 브라우저 저장소에 저장. 같은 근거면 재호출 없음(K-9 지문이 무효화 기준).
- **A 변환 응답 형식:** 지금 유니버스 JSON 틀(12.2) 그대로 + 노드·메모마다 `quote`. 스키마 검증 실패는 전체 거부 후 규칙 변환 결과 제시.

## 3. 요구사항 (01)

- **R-28 실시간 AI 변환·문장 다듬기(선택 기능):** ① 키가 없으면 화면·동작이 지금과 같다 ② 키를 넣으면 문서 탭에 「AI로 변환」, 초안·인사이트 설명에 「생성 중…」 뒤 실시간 문장과 「Claude API」 표시 ③ quote가 원문·근거에 없는 노드·문장은 버리고 건수를 보인다(테스트: 지어낸 quote 주입) ④ 호출 실패·시간 초과·오프라인이면 규칙 기반으로 돌아가고 원인이 보인다 ⑤ 키·응답 본문이 내보내기 파일·HTML·폴더 파일·이력에 들어가지 않는다(테스트) ⑥ 키를 지우면 즉시 지금 동작.
- 우선순위: P1(선택) — 제출물 기본 동작과 무관, 영상·소개자료용.

## 4. 작업 (03) — T-36·T-37

| T | 내용 | 검증 |

| T-36 | 연결부 비동기화 + 공급자 claude_api + 설정 키 칸 + CSP·빌드 예외 + 캐시 | 가짜 공급자(지연·실패·시간 초과·엉터리 응답)로 단위 테스트; 브라우저 점검은 가짜 공급자 주입(`?check`)으로 「생성 중」→교체→실패 대체; 키 비포함 테스트(내보내기·HTML·폴더·이력 grep) |

## 5. 위험

- 브라우저 직접 호출이 공식적으로 허용되는지·CORS 헤더(미확인 → 착수 전 확인, 안 되면 D-07b 로컬 중계로 전환하고 영상용으로만).

- 응답 지연으로 영상 흐름이 끊김 → 캐시된 응답으로 찍는다.
- 일정: 동결 10-26~27, 영상·소개자료 3일. 못 끝내면 A만 빼고 B만(1일) 또는 전부 중단해도 제출물은 그대로(기본 동작 불변).
