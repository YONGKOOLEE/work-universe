## 결정(D-34)
- ① 왜 덩어리는 **글과 CSS만**(이미지 없음, 파일 하나 원칙). ② 용어는 "처음 보이는 곳만" — 단추 이름 변경은 1차 후(점검 460여 항목·따라 하기 이름 결합). ③ 미리 보기는 **샘플 문장 재사용**(새 문장 생성 없음 → 사전 생성 지문 불변), 「샘플」 표시로 지어낸 것이 아님을 밝힘.
- 포기한 대안: 머리글 단추 전면 개명(지금 위험), 첫 화면을 그래프 대신 "내 업무 목록"으로(설계 변경, 1차 후 재료), 온보딩 동영상(파일 하나 원칙 위반).
