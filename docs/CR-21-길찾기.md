# CR-21 길 찾기 (기능 찾기 · 쓴 것 바로 보이기 · 개요 패널 정리)

- 문서: CR-21 v0.1 · 상태: **approved** (사용자 2026-10-25 23:40 무렵 "ABC는 진행하고" — `.status` approvals 맨 앞)
- 계기: 사용자 직접 사용(2026-10-25 밤) "메뉴찾기가 어려웠고 - 썼던게 어딨는지 헷갈림 … 가이드를 읽으면 좀 따라가기 쉬운데 과연 직관적으로 볼 수 있는지"
- 원인(메인 분석): ① 개요 패널에 상자가 쌓여(안내 글 → 미해결 → 편집 되감기 → 초안·인사이트 → 이번 주 기록 → 통합 확인 → 폴더 → 인사이트 설명 → 접힌 추가) 주·부 기능 구분이 없음 ② 고른 것(개요·업무·묶은 지도)에 따라 메뉴가 달라 위치를 외워야 함 ③ 기록하면 알림 한 줄뿐, 쓴 것이 어디 들어갔는지 안 보임
- 원칙: **옮기기·묶기·더하기만.** 기능·판정·저장 형식은 그대로. 기존 `data-testid`는 모두 유지(새로 더하는 것만 새 이름). 읽기 전용·내용 포함 HTML·되감기 중에는 편집 기능을 보이지 않는 기존 규칙 그대로.
- 범위 밖: 화면 구조 다시 짜기(D — 탭·작업 공간), 업무 상세 패널 재배치(1차 후)

## C. 개요 패널 정리 (아무것도 고르지 않은 화면)

1. 지도 이름·요약(dl) 바로 아래 **「무엇을 할까요?」 단추 4개**(한 줄, 좁으면 2×2): 「기록하기」 · 「인수인계」 · 「점검」 · 「지도 고치기」 (`data-testid` = `goal-record`·`goal-handover`·`goal-check`·`goal-edit`). 누르면 아래 해당 묶음으로 스크롤하고 그 묶음 머리를 잠깐 강조(약 1.5초 테두리 — 기존 강조 방식이 있으면 그것).
2. 그 아래 **목적별 묶음 4개**, 각 묶음은 머리글(h3)과 한 줄 설명을 가진 `<section data-testid="goal-sec-…">`. **접지 않는다**(보이던 것을 숨기면 기존 사용·점검이 깨짐 — 정리는 순서와 머리글로).
   - **기록하기** (`goal-sec-record`) — "업무에 메모·진행 상황을 남기고, 끝난 일을 해결로 표시합니다": 미해결 입구(issueEntry) → 「이번 주 기록」(weeklyBox) → **최근 기록**(B-2)
   - **인수인계** (`goal-sec-handover`) — "담당자가 바뀔 때 기록으로 초안을 만들고 확정합니다": 「인수인계 초안 만들기」 단추(primary) + 한 줄 "업무별 담당만 바꾸려면 그래프에서 업무를 고른 뒤 「담당 바꾸기」"
   - **점검** (`goal-sec-check`) — "인수인계 위험을 보고, 묶은 지도는 매주 점검을 저장해 비교합니다": 묶은 지도면 위험 요약·지난 점검 대비·바뀐 것 보기·저장 알림(지금 renderUniverseSummary의 riskSummary 부분을 이 묶음으로 옮김), 「인사이트 보기」 단추, 인사이트 설명 줄(insight-hint). 묶지 않은 지도면 "매주 점검은 팀·부서로 묶은 지도에서 합니다(「업무 지도 묶기」)" 한 줄 + 「인사이트 보기」
   - **지도 고치기** (`goal-sec-edit`) — "항목을 더하고 고치고, 이전 모습으로 되돌립니다": 「사람·업무·문서 추가」 열기 단추(아래 `details.add`를 펼치고 스크롤, `goal-add-open`) → 편집 되감기 입구(또는 묶은 지도 안내) → 숨긴 항목 입구 → 통합 확인(mergeButton) → 폴더 연결 입구 → 사번 확인 필요·사번 바뀐 연결 안내
3. 그 밖: 「처음 할 일」(starter)·미리 보기·split-hint는 지금처럼 **묶음보다 위**(새 지도에서 가장 먼저 필요). 맨 아래 일반 안내(hint, term-note)는 접힌 「처음이면 읽어 보세요」(`overview-help`, details)로.
4. 읽기 전용·되감기·내용 포함 HTML 보기에서는 편집 기능이 원래 안 보이는 규칙 그대로 — 묶음 안이 비면 그 묶음과 단추를 숨긴다.

## B. 쓴 것 바로 보이기

1. **기록 뒤 바로 가기:** 「이번 주 기록」·「해결로 표시」·업무 상세 「이력 추가」로 기록하면 기존 알림 줄 끝에 「이력에서 보기」 단추(`goto-history`). 누르면 그 업무를 고르고, 상세의 이력 목록에서 방금 기록한 줄로 스크롤해 강조(`data-just-added="1"`, 몇 초 뒤 강조만 사라짐). 업무 상세 「이력 추가」로 기록했을 때는 단추 없이 바로 그 줄을 강조. **(CR-22 F로 이름 바뀜 — 2026-10-26, 검토 RV11D-6: 지금은 패널 맨 위 성공 알림의 「거기로 가기」(같은 `goto-history`·같은 이동)이고, 카드 「기록 남기기」로 기록해도 그 줄 강조와 함께 알림·「거기로 가기」가 뜬다. 지금 동작은 01 「변경 CR-21·CR-22」 R-08 ⑧)**
2. **개요 「최근 기록」**(`recent-records`): 이 지도(묶은 지도면 묶인 지도 포함)의 사용자 기록(source가 user인 메모·인수인계·담당 시작/종료·소속 변경 등) **최근 5건**, 기록 시각 늦은 순. 줄마다 "날짜 · 업무(또는 대상) 이름 · 종류 · 내용 앞부분(40자)"과 「보기」(→ B-1과 같은 이동). 없으면 "아직 남긴 기록이 없습니다 — 「이번 주 기록」에 첫 기록을 남겨 보세요". 순수 계산은 `app/src/view/` 쪽 새 함수(단위 시험).

## A. 기능 찾기

1. 머리글 업무 지도 선택 오른쪽에 검색 칸 **「무엇을 할까요?」**(`feature-find`, placeholder "무엇을 할까요? 예: 담당, 미해결, 점검"). 글자를 치면 아래로 결과 목록(최대 6개, `feature-find-result`), 화살표·Enter·클릭으로 고름, Esc로 닫음.
2. 결과 한 줄: 기능 이름 + 위치 설명(예: "업무를 고른 뒤 → 「담당 바꾸기」") + 「바로 가기」. 고르면 그 자리로 데려가 강조:
   - 개요에 있는 것 → 선택 해제 후 해당 묶음/요소로 스크롤·강조
   - 업무를 골라야 하는 것(담당 바꾸기·이력 추가·협업자 추가·수정·연결 추가) → 지금 고른 업무가 있으면 그 상세의 해당 요소, 없으면 "그래프에서 업무를 먼저 고르세요" 안내와 함께 업무 이름 목록(최대 8개, 누르면 그 업무 상세의 해당 요소로)
   - 창으로 여는 것(가져오기·내보내기의 각 탭, 설정, 업무 지도 묶기, 새 업무 지도, 따라 하기 다시 보기, 글로 추가, 표로 추가) → 그 창·탭을 연다
3. 기능 목록(카탈로그)은 순수 모듈 `app/src/view/feature-index.js` 한 곳: `{ id, name, keywords[], where, needs: 'none'|'work'|'grouped'|'edit', go: '<동작 키>' }`. 최소: 이번 주 기록, 미해결·해결 표시, 최근 기록, 인수인계 초안, 담당도 넘기기(초안 확정), 담당 바꾸기, 이력 추가, 협업자 추가, 항목 수정, 연결 추가, 사람·업무·문서 추가(하나씩), 표로 추가, 글로 추가, 표로 고치기, 문서 가져오기(초벌 변환), JSON 내보내기·가져오기, 내용 포함 HTML, 폴더 연결, 업무 지도 묶기, 통합 확인 목록, 인사이트(인수인계 위험·밀집·공백·반복 비효율·유사 경험자·흐름 변화), 매주 점검(이번 점검 저장·지난 점검 대비), 점검 요약, 편집 되감기, 숨긴 항목, 시간 보기, 항목 찾기, 흐름 정렬·거르기, 설정(생성 방식·작성자 이름·Claude API 키), 따라 하기 다시 보기, 가상 데이터 초기화. 낱말 겹침·앞부분 일치·키워드(동의어: 담당/담당자/넘기기/인계, 메모/기록/이슈, 점검/위험/매주 등)로 점수, 동점은 목록 순서.
4. 읽기 전용 등에서 못 쓰는 기능은 결과에 "이 화면에서는 쓸 수 없음(이유)"로 흐리게. 묶은 지도에서 못 쓰는 것(글로 추가·편집 되감기)도 같은 방식.
