## 2. 계산·화면

| # | 한계 | 영향 |
|---|---|---|
| L-6 | 인사이트는 규칙 기반이다. 업무가 "비슷하다"는 주제·산출물 유형·낱말로만 판단한다(D-08). 인수인계서처럼 어떤 업무에나 생기는 산출물 유형은 비교에서 뺀다 | 주제·산출물 연결이 없는 업무는 "데이터 부족" |
| L-7 | 시간 슬라이더는 달 단위다. 기준일은 그 달의 마지막 날(이번 달은 오늘)이다 | 한 달 안의 변화는 이력 목록으로 본다 |
| L-8 | 조직 노드가 다른 유니버스에 있으면 업무 유니버스의 소속은 "미기재"로 보인다(소속 변경 메모를 함께 표시) | 통합 화면에서 조직관리와 함께 볼 때만 조직 이름이 보인다 |
| L-9 | 데이터가 끊긴 기간(마지막 입력 이후)은 0건으로 세지 않고 "입력 없음 — 데이터 부족"으로만 보인다 | 끊긴 기간의 인력 분포는 결론을 내지 않는다(R-05 ②) |
| L-13 | 같은 날짜의 인수인계를 나중 것부터 소급 입력하면(기록 시각이 거꾸로), 반복 비효율 ①이 순서를 기록 시각으로 정해 "이어받지 않음"으로 잘못 볼 수 있다(검토 2026-10-03) | 같은 날 여러 번 인계하는 경우는 드묾. 이전 인수인계 입력 칸은 지금 유니버스의 인수인계만 고를 수 있다 |
| L-14 | 문서 초벌 변환은 제목·표·목록 모양으로만 읽는다. 문장 속 의미(누가 무엇을 하는지)는 읽지 않으며, 모양이 아주 다른 문서는 절을 놓칠 수 있다 | 미리 보기의 「원문의 절 → 유니버스」 표로 확인하고, 가져온 뒤 고친다 |
