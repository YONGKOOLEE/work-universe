업무잇다 — 평소의 업무 기록이 곧 인수인계, 모이면 조직의 업무 지도 (1차 제출본)

■ 바로 보기
  1. 이 zip 파일의 압축을 풂 (압축을 풀지 않고 열면 일부 PC에서 동작하지 않을 수 있음)
  2. '업무잇다.html'을 더블클릭 → Chrome 또는 Edge에서 열림
  3. 설치·서버·로그인·인터넷 연결 없이 바로 확인 가능 (AI를 Claude로 쓰려면 본인 API 키와 인터넷이 필요함 — 아래 참고)

■ 처음 열면 보이는 내용 (시연용 가상 데이터 내장)
  - 부서 1곳·팀 2개, 사용자 7명(김도윤·이서연 등, 팀장 박지훈), 업무 8건, 문서·결정·조치·타임라인, 확정된 인계 1건
  - 상단 '사용자'에서 사람을 바꿔 보면 화면이 달라짐: 본인 담당 업무만 보임. 팀장(박지훈)은 전체를 봄

■ 직접 해 볼 것 (약 5분)
  1. 업무 유니버스(왼쪽 메뉴 맨 아래): 팀장으로 바꾸면 팀·부서 지도. 팀 도형을 두 번 누르면 펼침, 오른쪽 '지도 위험 점검'에 혼자만 아는 업무
  2. 지도에서 업무를 누르면 카드: 담당 넘기기·업무 잇기·메모·주제 → 업무 화면에 바로 반영
  3. 문서함 → '＋ 문서 등록' → '시연용_문서'의 '약관 개정 실무 회의록(시연용).pdf' → 'AI 분석' → 표의 과제·담당·기한이 담당자와 기한까지 이어진 반영 미리보기 → 승인 → 업무 상세 '업무 지도' 탭에서 확인
  4. 업무 인계 관리: 인계 시작 → AI 사전 점검 + '지도로 본 인계 포인트'(근거 칩) → 체크 → 제출 → 인수자로 전환 → 인수 확인 → 확정 → '인계 당시 스냅샷 조회'에서 인계 당시 지도 ↔ 지금 지도
  5. AI 업무 검색: '비대면 출금동의 현재 추진 경과는?'
  - 바꾼 내용은 이 PC의 브라우저에 저장됨. 상단 '초기화'로 처음 상태로 되돌릴 수 있음

■ AI 사용 (선택)
  - 키가 없으면 문서 분석·검색은 규칙 기반으로 동작함(밖으로 보내는 것 없음)
  - 상단 열쇠 단추('AI 설정')에 본인 Claude API 키를 넣으면 문서 분석·AI 검색·인계 포인트 다듬기를 Claude가 함. 키는 이 브라우저 저장소에만 저장되고 데이터 옮기기·백업에는 들어가지 않음. 호출은 api.anthropic.com으로만 감
  - AI가 낸 근거 구절은 앱이 원문과 직접 대조하고, 맞지 않으면 '추가 확인 필요'로 낮춤. 담당자가 승인한 항목만 업무에 반영됨
  - 실제 업무 문서는 회사의 외부 전송 기준을 확인한 뒤 사용. 공용 PC에서는 키를 넣지 말 것
