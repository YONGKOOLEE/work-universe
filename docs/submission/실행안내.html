업무 유니버스 — 실행 안내

업무 지식과 담당 이력을 그래프로 쌓아, 담당자가 바뀌어도 이어 볼 수 있게 하는 프로토타입입니다. 모든 사람·조직·업무는 가상입니다.

1. 여는 방법 (설치 없음)

  1. 받은 압축 파일을 풉니다(마우스 오른쪽 → 「압축 풀기」 또는 「모두 압축 풀기」).
  2. 풀린 폴더의 index.html을 더블클릭합니다. Chrome 또는 Edge로 열립니다.
  3. 인터넷 연결, 서버, 계정, 키가 필요 없습니다.

확인한 환경: Windows의 Chrome·Edge(버전 154). 그 밖의 브라우저(Safari, Firefox)와 macOS는 확인하지 못했습니다. 열리지 않으면 Chrome이나 Edge에서 파일을 끌어다 놓아 주세요.

2. 5분 둘러보기

  1. 처음 화면에서 「샘플 바로 열기: 월말 정산 점검」을 누릅니다.
  2. 동그라미(노드)를 누르면 오른쪽에 속성·연결·이력이 나옵니다. 「대사 확인」을 눌러 보세요(현재 담당, 반복 비효율 표시).
  3. 빈 곳을 누르고 「인수인계 초안 만들기」 → 보내는 사람 윤바다, 받는 사람 서하늘 → 「초안 만들기」. 항목마다 근거 버튼이 붙고, 근거가 없으면 "이력 부족"으로 표시됩니다.
  4. 「인사이트 보기」에서 유사 경험자·반복 비효율·밀집·공백·흐름 변화를 봅니다. 결정은 사람이 하고, 화면은 근거만 보여 줍니다.
  5. 그래프 아래 「시간 보기」 막대를 왼쪽으로 옮기면 그 시점의 담당자만 또렷하게 보입니다.
  6. 위쪽 목록에서 「가상 운영부 (부서)」를 고르면 여러 팀을 묶은 화면, 「가상본부 조직관리」는 조직개편과 입력 중단 사례입니다.

3. 화면에 보이는 "생성 방식"

표시뜻
사전 생성(개발 시 Claude로 작성)개발할 때 Claude가 가상 데이터의 근거만 보고 미리 써 둔 문장입니다(기본값).
규칙 기반기록을 규칙으로 옮겨 적은 문장입니다. 새로 입력한 데이터나 미리 쓴 문장이 없는 항목에 쓰입니다.

제출물에는 API 키가 없습니다. 실제 LLM(Claude API·사내 LLM) 연결은 1차 제출 범위 밖이며, 「생성 방식」 버튼에서 고르면 규칙 기반으로 동작하고 이유가 표시됩니다.

4. 알아 두실 점

  • 추가·수정한 내용은 이 브라우저 안에만 저장됩니다. 다른 PC나 다른 브라우저에는 보이지 않습니다. 옮기려면 「가져오기·내보내기」의 내보내기로 JSON 파일을 받아, 다른 PC에서 같은 버튼으로 가져옵니다.
  • 업무정의서 같은 문서는 「가져오기·내보내기」에 붙여 넣으면 규칙으로 읽어 유니버스 초벌을 만듭니다(「예시 문서 넣기」로 시험). 미리 보기에서 확인한 뒤 가져옵니다.
  • 오른쪽 위 「가상 데이터 초기화」를 누르면 처음 샘플 상태로 돌아갑니다.
  • 숨기기는 지우지 않고 기록을 남깁니다. 수정 전 값도 이력에 남습니다.
  • 다루지 않는 것: 재입사 등으로 사번이 바뀐 사람을 같은 사람으로 잇기, 여러 PC 사이의 자료 공유, 실제 사내 시스템 연결.
