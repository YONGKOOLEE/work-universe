# 업무잇다 검수 가이드 (초안, 2026-10-29)

사용자 확인용으로 대충 정리한 것. 기준: 최신 커밋(U-28 AI 엔진 3칸 반영).

## 0. 준비
- 받은 최신 `업무잇다-최종본-….html`을 더블클릭해서 엽니다. 꼬이면 오른쪽 위 「초기화」를 누릅니다.
- **사용자 바꾸기:** 상단 「사용자」 칸에서 고릅니다. 고칠 수 있는 범위는 조직 기준입니다(담당자, 그리고 조직장은 소속 조직 업무까지).
  - 김도윤: 팀원, 디지털신원팀
  - 박지훈: 디지털신원팀 팀장
  - 서지안: 전자금융부 부장(조직장 — 부 전체 업무·인계를 봄)
  - 정하준: 출금이체팀
- **화면 밝기:** 사용자 칸 옆 아이콘을 누를 때마다 자동 → 밝게 → 어둡게로 바뀝니다.
- **AI:** 상단 엔진 「규칙 · Claude · 사내」에서 고릅니다. 키가 없으면 모두 규칙으로 동작하고, 키를 넣으면 Claude를 고를 수 있습니다. 「사내」는 연결할 자리만 있어 고르면 규칙으로 동작합니다(안내가 뜸). 단추 이름은 엔진과 상관없이 「AI로 …」입니다.

## 2. API로 AI(Claude)를 쓰는 곳
키는 「AI 설정」에 넣으며 이 브라우저에만 저장됩니다. 백업 파일과 내보내기에는 들어가지 않습니다. 모든 곳에서 Claude가 낸 인용을 원문과 대조하고, 확인되지 않은 항목은 뺍니다.

| # | 위치 | 하는 일 | 보내는 것 | 키 없을 때 |
|---|---|---|---|---|
| A | 문서함 → 문서 등록 → 분석 | 문서에서 결정·일정·할 일(담당·기한)·업무 연결을 뽑음. 「꼼꼼히 읽기」를 켜면 첫 결과를 다시 대조하는 호출이 한 번 더 감 | 문서 본문, 업무·사람 목록 | 규칙 추출 |
| B | AI 업무 검색 (상단 검색창 포함) | 질문에 답하고 근거 문단을 단다. 업무 기록(담당·상태·기한)으로 답한 문장은 「업무 기록 요약(AI)」 칩 | 업무 기록(상태·담당·유의사항·협의처·조치 담당·기한)·문서 요약·관련 문단·오늘 날짜 | 규칙 답변 |
| C | 업무 상세 → 기록 점검 줄 「AI로 점검」 | 빠진 항목, 앞뒤가 안 맞는 내용, 기한 위험을 찾음. 마지막 결과는 저장(점검 일시·점검한 사람) | 그 업무의 기록 | 규칙 점검(기록 점검) |
| D | 인계 상세 → 사전 점검(키가 있으면 규칙 + AI), 「AI로 점검」 | 인계 전에 빠진 것과 위험을 점검 | 인계 대상 업무의 기록 | 규칙 사전 점검 |
| E | 업무 유니버스 → 인사이트 「AI로 더 찾기」 | 범위 안 업무들 사이의 숨은 인계 위험을 찾음(최대 8건). 예: 서로 상대를 기다리는 업무 | 범위 안 업무 기록 줄(「나만 보기」 메모는 제외) | 규칙 인사이트만 |
| F | 업무 유니버스 → 인사이트 「AI로 전체 인사이트」 | 범위 전체를 관통하는 발견 3~5개(왜 중요 · 다음 한 걸음). 서로 다른 업무 둘 이상의 원문 인용이 확인돼야 남김 | E와 같음 | 규칙 「한눈에」 한 줄 |
| G | 문서 상세 「다시 분석」 · 한눈에 보기 「근거 문서 다시 분석」 | 등록된 문서를 지금 엔진으로 다시 읽음(A와 같은 분석) | 문서 본문, 업무·사람 목록 | 규칙 분석 |

**확인 포인트:**
- 상단 「규칙 / Claude / 사내」 단추가 바뀌는지, 사내를 고르면 왼쪽 아래 안내가 「사내 LLM은 연결할 자리만…」으로 바뀌는지 확인합니다.
- 키를 넣은 뒤 A~G가 실제로 Claude로 동작하는지 확인합니다. 화면에 「AI」 또는 「규칙 기반」 표시가 나옵니다.
- 결과의 근거 칩을 누르면 원문 문단으로 가는지 확인합니다.
- 실패하거나 시간이 초과되면 규칙 결과로 돌아가는지 확인합니다.

## 3. 알려진 한계·미확인
- **키를 넣은 화면:** 브라우저 자동 점검으로 보지 않았습니다(점검 도구가 외부 통신을 막음). 실제 키로 기능 시험은 했습니다(인사이트 8건, 점검 2/2).
- **저장:** 사람마다 브라우저에 따로 저장됩니다. 실시간 공유는 없고 「합쳐 불러오기」로 모읍니다.
- **합쳐 불러오기:** 한 파일에 이름이 같은 업무가 둘 들어오는 드문 경우는 시험하지 않았습니다.
- **조직 지우기:** 확인 창 없이 바로 지워집니다(쓰이는 조직은 막힘).
- **시안 단추:** 기본·가 우주·나 정돈은 비교용으로 남겨 두었습니다. 제출 전에 정리할지 정해야 합니다.
- **Edge:** 이번 묶음은 Chrome으로만 점검했습니다. Edge는 제출 압축 때 한 번 점검합니다.

## 5. 합쳐 불러오기 — 자세히
동료가 쓴 업무를 내 화면(팀 지도)에 더할 때 씁니다. 데이터는 사람마다 자기 브라우저에 있으므로 파일로 주고받습니다.

1. **동료:** 상단 오른쪽 **「데이터 옮기기」**(↕ 아이콘, 창이 좁으면 아이콘만) → **내보내기** → **백업 파일 저장**(.json) → 파일 전달. 저장이 안 되면 「내용 복사」.
2. **나:** **「데이터 옮기기」** → **불러오기** → **합쳐 불러오기**(기본으로 골라져 있음) → **백업 파일 선택**(또는 아래 칸에 붙여 넣기). 상단 「바로 찾기」(Ctrl+K)에 「합쳐」를 쳐도 바로 열립니다.
3. **미리 보기에서 고르기**
   - 사람 맞춤: 사번이 같으면 같은 사람으로 맞춥니다.
   - 업무마다 「새로 더하기 / 같은 업무로 합치기 / 따로 두기」. 이름이 같은 업무가 여럿이면 합칠 대상을 고릅니다.
   - 같은 업무인데 내용이 다른 칸: 서술 칸은 둘 다 남기기, 한 값 칸은 지금 것이 기본이고 칸마다 바꿀 수 있습니다.
4. **「합쳐 불러오기」** 단추 → 몇 건이 더해졌는지 알림. 같은 파일을 두 번 합쳐도 늘어나지 않습니다.
5. **들어오지 않는 것:** 동료의 「나만 보기」 메모, 지도 숨김, AI 키, 내가 지운 문서(「삭제한 문서 n건」으로 표시).

## 7. AI 비서 — 따라 하면서 확인하기

시작 전에: 파일을 열고 왼쪽 메뉴 맨 아래쪽 **「AI 비서」**를 누릅니다. 상단 사용자 칸이 **김도윤**인지 봅니다. 아래 순서대로 하면 됩니다. 꼬이면 오른쪽 위 「초기화」를 누르면 처음 상태로 돌아갑니다(직접 넣은 고객도 지워집니다).

### 7-1. 오늘 화면
안쪽 탭 **「오늘」**에서 봅니다. 여기 내용은 고객·활동·요청·경조사에 입력된 값으로 계산한 것입니다.
1. 「오늘 할 일」에 조성훈(기한 지난 요청), 김도현(오늘 기한 요청)이 있는지 봅니다.
2. 「미팅 후 질문 대기」에 윤지아가 있는지 봅니다.
3. 오른쪽 「알림」에서 아무 줄의 **「읽음」**을 누릅니다 → 왼쪽 메뉴 「AI 비서」 옆 숫자가 1 줄어야 합니다.

### 7-2. 고객 찾기
안쪽 탭 **「고객」**을 누릅니다. 18명이 보여야 합니다.
1. 찾기 칸에 `골프`를 입력합니다 → 김도현, 조성훈 2명만 남아야 합니다. 칸을 비웁니다.
2. 위쪽 칩 **「정부기관」**을 누릅니다 → 3명만 남아야 합니다. **「전체」**를 눌러 되돌립니다.

### 7-3. 값 고치고 되돌리기 (가이드 24번)
1. 목록에서 **김도현**을 누릅니다.
2. 이름 아래 탭에서 **「선호·관심사」**를 누릅니다 → 기피 음식이 `해산물`입니다.
3. 오른쪽 위 **「수정」**을 누릅니다.
4. 창에서 「기피 음식」 칸을 `해산물, 매운 음식`으로 바꾸고 창 아래 **「저장」**을 누릅니다 → 「저장했습니다 · 1개 항목 변경」이 떠야 합니다.
5. 탭 **「변경 이력」**을 누릅니다 → 「이전 해산물 / 이후 해산물, 매운 음식」 줄이 있어야 합니다.
6. 그 줄의 **「이전 값으로 복원」**을 누릅니다.
7. **「선호·관심사」**로 돌아갑니다 → 기피 음식이 다시 `해산물`이어야 합니다. 「변경 이력」에는 복원한 줄이 하나 더 쌓입니다.

### 7-4. 미팅 브리핑
1. 김도현 화면에서 오른쪽 위 **「미팅 브리핑」**을 누릅니다.
2. 창에 최근 만남, 선호·기피 음식, 미처리 요청, 이번 미팅 확인사항이 한 장으로 나오는지, 30초 정도에 읽히는지 봅니다.
3. 창을 닫습니다(「인쇄」는 눌러 보셔도 됩니다. 인쇄 결과는 제가 확인하지 못했습니다).

### 7-5. 미팅 후 질문
1. 안쪽 탭 **「오늘」** → 「미팅 후 질문 대기」의 윤지아 줄에서 **「질문 답하기」**를 누릅니다.
2. 첫 질문은 **「예정대로 진행됨」**을 고릅니다.
3. 둘째 질문은 **「자료 요청」**을 고르고 요청 내용에 `관리비 안내 자료`를 적습니다.
4. 음식 질문이 나오면 **「일식」**처럼 아무거나 고릅니다.
5. 아래 **「답변 확인」**을 누릅니다 → 저장할 항목이 체크된 채 나옵니다.
6. 항목 하나의 체크를 풀고 아래 **「체크한 N건 저장」**을 누릅니다 → 그 고객의 히스토리 화면으로 이동합니다.
7. 윤지아 고객 화면의 **「요청」**·**「히스토리」** 탭에서, 체크한 것만 들어갔는지 봅니다.

### 7-6. 요청 끝내기
1. 안쪽 탭 **「활동·요청」** → **「요청사항」**을 누릅니다.
2. 김도현의 `최근 6개월 CMS 거래실적 자료 제공` 줄의 진행 상태를 **「완료」**로 바꿉니다.
3. **「오늘」** 탭으로 갑니다 → 오늘 할 일과 알림에서 그 요청이 사라져야 합니다.

### 7-7. 대화 분석 — 키 없이 예시로
1. 안쪽 탭 **「대화 분석」**을 누릅니다.
2. 고객은 **강하은**을 고릅니다(예시 값이 실제로 들어가니 김도현 말고 다른 고객으로).
3. 오른쪽 아래 **「예시 분석 체험 (AI 미사용)」**을 누릅니다.
4. 항목마다 근거 문장, 화자, 신뢰도가 나오는지, 맨 위에 「예시 분석(AI 미사용)」과 「시험용」 표시가 있는지 봅니다.
5. 추측인 「연말 인사 이동」 항목은 체크가 풀려 있어야 합니다.
6. 아래 **「선택한 항목 저장」**을 누릅니다 → 강하은 고객의 선호·관심사와 히스토리에 들어가야 합니다.

### 7-8. 대화 분석 — 키로 실제 AI 분석
(이 단계만 제가 화면에서 실제 키로 눌러 보지 않았습니다. 같은 분석 호출은 시험으로 확인했습니다.)
1. 상단 엔진 칸에서 **Claude**를 고릅니다(키가 없으면 상단 열쇠 모양 「AI 설정」에서 넣습니다).
2. **「대화 분석」** 탭에서 고객을 고르고 대화 내용을 붙여 넣습니다. 전화번호를 하나 섞어 봅니다.
3. **「전송 내용 확인」**을 누릅니다 → 보낼 글이 그대로 나오고 전화번호는 `[휴대전화]`로 가려져야 합니다.
4. 동의 칸을 체크하고 **「동의하고 AI로 분석」**을 누릅니다(최대 2분).
5. 결과 항목을 보고 **「선택한 항목 저장」** 또는 **「버리기」**를 누릅니다.

### 7-9. 묻기
안쪽 탭 **「묻기」**의 입력 칸에 그대로 넣습니다. 엔진은 「규칙」 기준 결과입니다.

| 입력 | 나와야 하는 결과 |
|---|---|
| `해산물 못 드시는 분` | 김도현 1명, 근거에 기피 음식 해산물 |
| `김도현 못 먹는 음식` | 김도현 1명, 기피 음식 해산물 |
| `이서연 골프` | 0명, 「이서연 고객에게서 '골프'를 찾지 못했습니다」 |
| `이번 주 미팅` | 장태우, 김도현 2명 |
| `기한 지난 요청` | 기한 지난 요청 목록 |
| `모든 고객` | 18명 |
| `주요 고객` | 「질문을 이해하지 못했습니다」 안내 |

결과의 고객 이름을 눌러 상세로 갔다가 왼쪽 위 **‹** 를 누르면 검색 결과가 그대로 있어야 합니다.

### 7-10. 위쪽 검색 두 개
1. AI 비서 화면에서 맨 위 검색 칸이 「고객에 대해 질문하세요」로 바뀌어 있는지 봅니다. `골프 좋아하는 은행 담당자`를 넣고 Enter를 누릅니다 → 「묻기」로 이동해 김도현이 나와야 합니다.
2. `Ctrl + K`를 누르고 `김도현`을 넣습니다 → 고객이 나오고, 누르면 상세로 가야 합니다.

### 7-11. 사용자 바꿔 보기
1. 상단 사용자 칸에서 **이서연**을 고르고 「오늘」 탭을 봅니다 → 담당 고객이 없다는 안내가 나옵니다. **「전체 보기」**를 누르면 고객 내용이 보여야 합니다.
2. 「고객」 탭에서 김도현을 엽니다 → 잠금 안내가 있고 「수정」·「삭제」가 눌리지 않아야 합니다.
3. 사용자를 **박지훈**으로 바꿉니다 → 김도현을 고칠 수 있고 「조직장이라 수정할 수 있습니다」가 보여야 합니다.
4. 사용자를 **김도윤**으로 돌려놓습니다.

### 7-12. 설정과 삭제
1. 오른쪽 위 **「설정」**을 누릅니다.
2. **「가상 데이터 삭제」**를 누르고 확인합니다 → 고객 탭이 비어야 합니다(직접 등록한 고객은 남습니다).
3. 다시 설정에서 **「가상 데이터 다시 채우기」**를 누릅니다 → 18명이 돌아와야 합니다.

### 알아 둘 것
- 백업 파일에 고객 데이터도 들어갑니다(사용자 결정 U-38). 화면 경고는 넣지 않았습니다(U-40).
- 알림은 탭을 연 동안만 보입니다. Windows 알림·자동 실행은 없습니다.
- 명함 인식·사진·음성 변환·Google 캘린더는 넣지 않았습니다. 업무 연결은 CR-25 4.5절에 후보 설계로만 있습니다.
