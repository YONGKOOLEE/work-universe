# 업무잇다 검수 가이드 (초안, 2026-10-29)

사용자 확인용으로 대충 정리한 것. 기준: 최신 커밋(U-28 AI 엔진 3칸 반영).

## 0. 준비
- 받은 최신 `업무잇다-최종본-….html`을 더블클릭해서 엽니다. 꼬이면 오른쪽 위 「초기화」를 누릅니다.
- **사용자 바꾸기:** 상단 「사용자」 칸에서 고릅니다. 고칠 수 있는 범위는 조직 기준입니다(담당자, 그리고 조직장은 소속 조직 업무까지).
  - 김도윤: 팀원, 디지털신원팀
  - 박지훈: 디지털신원팀 팀장
  - 서지안: 전자금융부 부장(조직장 — 부 전체 업무·인계를 봄)
  - 정하준: 출금이체팀
- **화면 밝기:** 사용자 칸 옆 아이콘을 누를 때마다 자동 → 밝게 → 어둡게로 바뀝니다.
- **AI:** 상단 엔진 「규칙 · Claude · 사내」에서 고릅니다. 키가 없으면 모두 규칙으로 동작하고, 키를 넣으면 Claude를 고를 수 있습니다. 「사내」는 연결할 자리만 있어 고르면 규칙으로 동작합니다(안내가 뜸). 단추 이름은 엔진과 상관없이 「AI로 …」입니다.

## 2. API로 AI(Claude)를 쓰는 곳
키는 「AI 설정」에 넣으며 이 브라우저에만 저장됩니다. 백업 파일과 내보내기에는 들어가지 않습니다. 모든 곳에서 Claude가 낸 인용을 원문과 대조하고, 확인되지 않은 항목은 뺍니다.

| # | 위치 | 하는 일 | 보내는 것 | 키 없을 때 |
|---|---|---|---|---|
| A | 문서함 → 문서 등록 → 분석 | 문서에서 결정·일정·할 일(담당·기한)·업무 연결을 뽑음. 「꼼꼼히 읽기」를 켜면 첫 결과를 다시 대조하는 호출이 한 번 더 감 | 문서 본문, 업무·사람 목록 | 규칙 추출 |
| B | AI 업무 검색 (상단 검색창 포함) | 질문에 답하고 근거 문단을 단다. 업무 기록(담당·상태·기한)으로 답한 문장은 「업무 기록 요약(AI)」 칩 | 업무 기록(상태·담당·유의사항·협의처·조치 담당·기한)·문서 요약·관련 문단·오늘 날짜 | 규칙 답변 |
| C | 업무 상세 → 기록 점검 줄 「AI로 점검」 | 빠진 항목, 앞뒤가 안 맞는 내용, 기한 위험을 찾음. 마지막 결과는 저장(점검 일시·점검한 사람) | 그 업무의 기록 | 규칙 점검(기록 점검) |
| D | 인계 상세 → 사전 점검(키가 있으면 규칙 + Claude), 「AI로 점검」 | 인계 전에 빠진 것과 위험을 점검 | 인계 대상 업무의 기록 | 규칙 사전 점검 |
| E | 업무 유니버스 → 인사이트 「AI로 더 찾기」 | 범위 안 업무들 사이의 숨은 인계 위험을 찾음(최대 8건). 예: 서로 상대를 기다리는 업무 | 범위 안 업무 기록 줄(「나만 보기」 메모는 제외) | 규칙 인사이트만 |
| F | 업무 유니버스 → 인사이트 「AI로 전체 인사이트」 | 범위 전체를 관통하는 발견 3~5개(왜 중요 · 다음 한 걸음). 서로 다른 업무 둘 이상의 원문 인용이 확인돼야 남김 | E와 같음 | 규칙 「한눈에」 한 줄 |
| G | 문서 상세 「다시 분석」 · 한눈에 보기 「근거 문서 다시 분석」 | 등록된 문서를 지금 엔진으로 다시 읽음(A와 같은 분석) | 문서 본문, 업무·사람 목록 | 규칙 분석 |

**확인 포인트:**
- 상단 「규칙 / Claude / 사내」 단추가 바뀌는지, 사내를 고르면 왼쪽 아래 안내가 「사내 LLM은 연결할 자리만…」으로 바뀌는지 확인합니다.
- 키를 넣은 뒤 A~G가 실제로 Claude로 동작하는지 확인합니다. 화면에 「Claude」 또는 「규칙 기반」 표시가 나옵니다.
- 결과의 근거 칩을 누르면 원문 문단으로 가는지 확인합니다.
- 실패하거나 시간이 초과되면 규칙 결과로 돌아가는지 확인합니다.

## 3. 알려진 한계·미확인
- **키를 넣은 화면:** 브라우저 자동 점검으로 보지 않았습니다(점검 도구가 외부 통신을 막음). 실제 키로 기능 시험은 했습니다(인사이트 8건, 점검 2/2).
- **저장:** 사람마다 브라우저에 따로 저장됩니다. 실시간 공유는 없고 「합쳐 불러오기」로 모읍니다.
- **합쳐 불러오기:** 한 파일에 이름이 같은 업무가 둘 들어오는 드문 경우는 시험하지 않았습니다.
- **조직 지우기:** 확인 창 없이 바로 지워집니다(쓰이는 조직은 막힘).
- **시안 단추:** 기본·가 우주·나 정돈은 비교용으로 남겨 두었습니다. 제출 전에 정리할지 정해야 합니다.
- **Edge:** 이번 묶음은 Chrome으로만 점검했습니다. Edge는 제출 압축 때 한 번 점검합니다.

## 5. 합쳐 불러오기 — 자세히
동료가 쓴 업무를 내 화면(팀 지도)에 더할 때 씁니다. 데이터는 사람마다 자기 브라우저에 있으므로 파일로 주고받습니다.

1. **동료:** 상단 오른쪽 **「데이터 옮기기」**(↕ 아이콘, 창이 좁으면 아이콘만) → **내보내기** → **백업 파일 저장**(.json) → 파일 전달. 저장이 안 되면 「내용 복사」.
2. **나:** **「데이터 옮기기」** → **불러오기** → **합쳐 불러오기**(기본으로 골라져 있음) → **백업 파일 선택**(또는 아래 칸에 붙여 넣기). 상단 「바로 찾기」(Ctrl+K)에 「합쳐」를 쳐도 바로 열립니다.
3. **미리 보기에서 고르기**
   - 사람 맞춤: 사번이 같으면 같은 사람으로 맞춥니다.
   - 업무마다 「새로 더하기 / 같은 업무로 합치기 / 따로 두기」. 이름이 같은 업무가 여럿이면 합칠 대상을 고릅니다.
   - 같은 업무인데 내용이 다른 칸: 서술 칸은 둘 다 남기기, 한 값 칸은 지금 것이 기본이고 칸마다 바꿀 수 있습니다.
4. **「합쳐 불러오기」** 단추 → 몇 건이 더해졌는지 알림. 같은 파일을 두 번 합쳐도 늘어나지 않습니다.
5. **들어오지 않는 것:** 동료의 「나만 보기」 메모, 지도 숨김, AI 키, 내가 지운 문서(「삭제한 문서 n건」으로 표시).
