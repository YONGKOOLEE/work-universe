# 시연 영상 대본 — 업무잇다(통합 제품) v1.0 (2026-10-31)

- 기준: CR-24 통합 제품(itda). 이전 대본(docs/시연-대본-초안.md)은 업무 유니버스 단독 제품 기준이라 참고만 한다.
- 길이 3분 이내(녹화본 2분 28초). 하단 한국어 자막, 음성 없음(사용자 결정 2026-10-31 「진행」). 클릭 위치는 빨간 원으로 표시한다.
- 화면 1440×900. 시연 데이터(가상 10명·15업무·조직 10개·고객 18명). 문서는 「약관 개정 실무 회의록(시연용).pdf」(itda/tools/make-demo-pdfs.mjs).
- AI: 본인 키로 실제 Claude를 쓴다(화면에 키는 나오지 않음). 키 없이 찍으면 같은 흐름이 규칙 기반 결과로 나온다.
- 자동 녹화 도구: itda/tools/record-demo.mjs(대본의 장면을 그대로 실행, 자막·클릭 표시를 화면에 그려 MP4로 저장).

## 한 줄 메시지

평소의 업무 기록이 곧 인수인계가 되고, 기록이 모이면 조직의 업무 지도가 됩니다. AI는 원문에 있는 것만 제안하고, 앱이 검사하고, 사람이 승인합니다.

- 화면 배율 100%, 창 1440×900.
