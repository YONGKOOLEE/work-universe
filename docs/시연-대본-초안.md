# 시연 영상 대본 초안 (3분)

- 문서명: 시연 대본 초안 v0.1 · 상태: draft(사용자 확인 전) · 작성 2026-10-05 · 관련: T-16(영상·소개자료), R-03·R-05·R-14·R-17
- 대상: 영상을 찍는 사용자(말할 내용과 누를 순서). 화면 이름·버튼 이름은 실제 앱 그대로이며, 실행 안내의 "5분 둘러보기"와 같은 길입니다.
- 이 문서는 **초안**입니다. 영상은 기능 동결 뒤에 찍고, 찍기 직전에 아래 "찍기 전 확인"을 다시 해야 합니다.

## 한 줄 메시지
담당자가 바뀔 때 "누가 무엇을 어떻게 해 왔는지"가 사람 머릿속에서만 넘어가던 것을, **기록이 쌓이는 그래프**로 남기고 **인수인계 초안을 근거와 함께** 만들어 준다.

## 장면 구성

| # | 시간 | 화면 | 누를 것 | 말할 내용 |
|---|---|---|---|---|
| 1 | 0:00~0:20 | 시작 화면 | 「샘플 바로 열기: 월말 정산 점검」 | 문제: 매월 반복되는 정산 점검. 담당자가 바뀔 때마다 인수인계가 구두로 끝나고, 다음 사람은 처음부터 다시 배운다. 이 화면은 모두 가상 데이터. |
| 2 | 0:20~0:55 | 월말 정산 점검 그래프 | 「대사 확인」 노드 클릭 → 이력까지 내리기 | 업무 하나에 속성(주기·마감·절차·주의사항)과 이력이 붙는다. 한가람 → 윤바다는 **문서**로, 윤바다 → 서하늘은 **구두**로 넘어갔다는 기록이 남아 있다. 「반복 비효율」 표시: 두 번째 인수인계는 이전 인수인계서를 이어받지 않았다. |
| 3 | 0:55~1:30 | 인수인계 초안 | 빈 곳 클릭 → 「인수인계 초안 만들기」 → 보내는 사람 윤바다, 받는 사람 서하늘 → 「초안 만들기」 | 이력에서 필요한 내용을 모아 10개 항목으로 초안을 만든다. 문장마다 **근거 버튼**이 붙고, 누르면 그래프에서 그 노드가 강조된다. 근거가 없는 항목은 지어내지 않고 「이력 부족」으로 표시한다. 필요하면 「패널 넓게 보기」. |
| 4 | 1:30~1:55 | 초안 아래 확정 상자 | 「확정해 인수인계서로 저장」 | 사람이 확인하고 확정하면 인수인계서와 인수인계 이력이 남는다. 다음 초안의 「이전 인수인계」에 이 인수인계서가 근거로 나타난다. 결정은 사람이 한다. |
| 5 | 1:55~2:20 | 「인사이트 보기」 → 「밀집·공백」 | 탭 이동 | 「자료 수집」과 「보고」는 윤바다가 맡다가 9월 말에 끝났는데 **후임이 없다**. 구두 인수인계에 빠진 업무가 한눈에 드러난다(공백). |
| 6 | 2:20~2:50 | 위쪽 목록에서 「가상 운영부 (부서)」 | 「노드 찾기」에 "대사" 입력 → 고르기 → 「주변만 보기」 | 업무 → 팀 → 부서로 같은 틀로 묶는다. 노드가 많아도 찾기·주변만 보기로 읽는다. 팀 사이의 비슷한 업무(유사 경험자)와 사번이 같은데 이름이 다른 사람은 **자동으로 합치지 않고 사람이 확인**한다. |
| 7 | 2:50~3:00 | 「가져오기·내보내기」 | 「예시 문서 넣기」 → 「초벌 변환」 | 기존 업무정의서도 붙여 넣으면 규칙으로 읽어 유니버스 초벌을 만든다. 마무리: 입력 부담은 문서 변환과 표 입력으로 줄이고, 실제 도입에는 권한·저장 같은 확장이 필요하다(전환 경로 문서). |

## AI 활용을 말하는 방법 (심사 항목 대응)
- 규칙이 근거를 찾고, 문장은 개발 때 Claude로 미리 써 두며(사전 생성), **앱이 모든 문장의 근거를 검증**한다. 근거가 없으면 규칙 기반 문장으로 바꾸고, 이력이 없으면 「이력 부족」이라고 쓴다.
- 이 앱 자체도 Claude Code로 설계·구현·검증했다(단위 테스트, 브라우저 점검, 검토 에이전트로 결함을 찾아 고침). 숫자는 영상 직전에 다시 센다: `npm test`의 통과 개수.
- 실시간 호출을 넣지 않은 이유: 키·과금·보안, 그리고 더블클릭만으로 열려야 하는 실행 조건. 연결부는 만들어 두었고 공급자 자리만 비어 있다.

## 찍기 전 확인
1. 가장 새 제출본을 새 프로필(또는 「가상 데이터 초기화」 후)에서 연다. 처음 상태가 아니면 장면 2·5의 숫자가 다르다.
2. 화면 크기 1366×768 이상, 브라우저 확대 100%. 노드 이름이 작으면 마우스를 올리거나 장면 6의 찾기를 쓴다.
3. 장면 4에서 확정하면 데이터가 바뀐다. 다시 찍으려면 「가상 데이터 초기화」.
4. 장면 6의 "가상 운영부"는 처음 열 때 통합 확인 대기 건수가 보인다. 업무 후보 첫 항목은 엉뚱해 보일 수 있으니 목록 아래쪽의 「장소 섭외 ↔ 강의실·강사 섭외」와 사번 충돌(윤바다/윤바다라)을 보여 준다.
5. 영상 길이·형식·용량 제한은 주최 측 공지로 확인한다(00-context에 미확인으로 남아 있음).

## 사용자가 정할 것

- 목소리 설명이 영상 안에 들어가는지, 자막만 쓰는지.
